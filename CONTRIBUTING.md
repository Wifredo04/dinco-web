# Contribuir al repositorio

Por favor sigue estas reglas al crear commits en este repositorio:

- Escribe los mensajes de commit en español.
- El título debe ser una línea breve en español.
- Añade una descripción que explique los cambios realizados y por qué se hicieron.

Ejemplo de mensaje de commit:

Resumen breve en español (una línea)

Descripción:
- Cambios: Se modificó `components/Hero.tsx` para corregir un error de hook.
- Por qué: Evitar warnings de ESLint y mejorar la estabilidad del carousel.

Hemos añadido hooks Git que insertan una plantilla en español automáticamente
y validan que el mensaje contenga una explicación en español.
